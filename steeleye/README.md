## Setup

## Overview

This project implements a data pipeline that:

1. Downloads XML data from ESMA
2. Extracts the DLTINS dataset
3. Parses data
4. Transforms it into a structured format using Pandas
5. Outputs the result as a CSV file

## Output

The pipeline generates:

- data/output.csv → final dataset
